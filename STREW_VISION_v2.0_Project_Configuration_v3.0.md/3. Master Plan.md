## 3.5 Responsibility

각 Volume은 자신의 책임만 수행한다.

Volume 간 역할은 변경하지 않는다.

Platform Design과 Functional Design의 책임을 혼합하지 않는다.

---

## 3.6 Frozen Rule

Master Plan은 프로젝트 종료 시까지 변경하지 않는다.

새로운 Volume을 추가하지 않는다.

기존 Volume을 삭제하지 않는다.

Volume 순서를 변경하지 않는다.

Volume의 책임을 변경하지 않는다.

필요한 내용은 해당 Volume 내부에서만 보완한다.

---

## 3.7 Relationship

↓

Foundation는 시스템을 설명한다.

Platform Design은 프로젝트를 설명한다.

Functional Design은 기능을 설명한다.

모든 설계 문서는 이 순서를 따른다.

## 3.8 Frozen Volumes

다음 항목은 프로젝트 종료 시까지 변경하지 않는다.

- Master Plan
- Volume Structure
- Volume Responsibility
- Documentation Architecture

이미 Frozen된 Volume은

Chapter 구조를 변경하지 않는다.

목차를 변경하지 않는다.

기존 설계 철학을 변경하지 않는다.
