# 8. Claude Review Template

---

## 8.1 Purpose

문서 작성이 완료되면

Claude를 이용하여 설계를 검증한다.

Claude는

새로운 설계를 작성하지 않는다.

기존 문서를 검토하는 역할만 수행한다.

---

## 8.2 Review Prompt

다음 설계 문서를 검토하시오.

검토 기준

1.

실제 코드(as-is)와 일치하는가

2.

기존 Volume과 충돌하는가

3.

중복 설명이 존재하는가

4.

설계 문서로 적절한가

5.

추측이 포함되어 있는가

6.

논리적 오류가 존재하는가

7.

개선이 필요한 부분이 있는가

오류가 없다면

"문제 없음"

만 출력한다.

오류가 있다면

수정이 필요한 부분만 알려준다.

새로운 구조를 제안하지 않는다.
