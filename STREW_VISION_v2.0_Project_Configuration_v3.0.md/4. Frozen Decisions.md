# 4. Frozen Decisions

---

## 4.1 Purpose

Frozen Decision은 프로젝트 진행 중 확정된 설계 결정을 기록하는 규칙이다.

한 번 Frozen된 Decision은 프로젝트 종료 전까지 변경하지 않는다.

새로운 AI 세션에서는 반드시 Frozen Decision을 먼저 확인한 후 문서를 작성한다.

---

## 4.2 Decision-001

### Foundation 구조 고정

Foundation은 프로젝트와 전체 시스템만 설명한다.

구성

- Volume01
- Volume02

Platform 내부 구현은 Foundation에서 설명하지 않는다.

Status

Frozen

---

## 4.3 Decision-002

### Platform Design 구조 고정

Platform Design은 실제 프로젝트(as-is)를 설명한다.

구성

- Volume03
- Volume04
- Volume05

Platform Design은 코드 구조를 설명하는 문서이다.

Status

Frozen

---

## 4.4 Decision-003

### Functional Design 구조 고정

Functional Design은 기능을 설명한다.

구성

Volume06 ~ Volume20

기능의

- 목적
- 역할
- 데이터 흐름
- 운용 방식

을 설명한다.

Status

Frozen

---

## 4.5 Decision-004

### SQLite 위치 고정

SQLite는 Jetson Software의 Storage Module이다.

SQLite는 독립 Platform으로 분리하지 않는다.

Volume04에서 설명한다.

Status

Frozen

---

## 4.6 Decision-005

### AWS Platform 구조 고정

Volume05는

AWS Server & Dashboard Design

으로 구성한다.

AWS Platform 전체를 설명한다.

포함

- FastAPI
- REST API
- Dashboard
- DynamoDB
- MQTT
- OTA
- WebRTC

Status

Frozen

---

## 4.7 Decision-006

### Platform 구현 반복 금지

Platform Design에서 설명한 구현(as-is)은

Functional Design에서 반복 설명하지 않는다.

Status

Frozen

---

## 4.8 Decision-007

### Functional 구현 상세 금지

Functional Design은

- 개념
- 역할
- 목적
- 흐름

만 설명한다.

클래스 구조

Runtime

Module

Event

Initialization

등은 설명하지 않는다.

Status

Frozen

---

## 4.9 Decision-008

### Master Plan 변경 금지

다음 항목은 변경하지 않는다.

- Volume 구조
- Volume 순서
- Volume 책임

필요한 내용은

해당 Volume 내부에서만 수정한다.

Status

Frozen

---

## 4.10 Decision-009

### Frozen Volume 보호

이미 Frozen된 Volume은

다음 항목을 변경하지 않는다.

- Chapter
- 목차
- 설계 철학
- 책임 범위

오류 수정 외의 구조 변경은 금지한다.

Status

Frozen

---

## 4.11 Decision-010

### Source of Truth

프로젝트의 판단 기준은

Priority 1

Frozen Volume

↓

Priority 2

Notion Design

↓

Priority 3

Source Code

↓

Priority 4

사용자 승인

↓

Priority 5

AI 일반 지식

AI의 일반 지식은

프로젝트 설계보다 우선하지 않는다.

Status

Frozen

---
## Decision-011

### 실제 문서 우선 원칙

이미 작성된 Volume과

실제 프로젝트 구조가

Master Plan보다 우선한다.

Master Plan은

실제 프로젝트를 설명하기 위한 문서이다.

프로젝트를

Master Plan에 맞추기 위해

억지로 수정하지 않는다.

Status

Frozen

## 4.12 Principle

모든 AI는

Frozen Decision을

최우선 규칙으로 사용한다.

Frozen Decision과 충돌하는 내용은

제안할 수는 있지만

사용자의 승인 없이 변경할 수 없다.
