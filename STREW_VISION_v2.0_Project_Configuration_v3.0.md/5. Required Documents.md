# 5. Required Documents

---

## 5.1 Purpose

새로운 GPT 세션에서는 프로젝트 상태를 복원하기 위해 필요한 자료를 먼저 확인한다.

필수 자료가 준비되지 않은 경우 문서 작성을 시작하지 않는다.

---

## 5.2 Required Documents

프로젝트 시작 시 다음 자료를 우선적으로 확인한다.

### Project Configuration

현재 Project Configuration

(STREW_VISION Project Configuration)

---

### Design Documents

Notion Export

또는

최신 설계 문서

---

### Source Code

Jetson Source

AWS Source

필요 시

Arduino Source

---

### Frozen Documents

현재까지 작성 완료된 Volume

예)

Volume01

Volume02

Volume03

Volume04

---

## 5.3 Current Working Position

현재 작업 위치를 확인한다.

예시

Current Volume

Volume05

Current Chapter

Chapter01

Current Status

Draft

---

## 5.4 Missing Documents

필수 자료가 없으면

AI는 반드시 사용자에게 요청한다.

예)

□ Project Configuration

□ Notion Export

□ Jetson Source

□ AWS Source

□ Arduino Source (필요 시)

□ Frozen Volume

---

## 5.5 Priority

자료 확인 우선순위

1.

Project Configuration

↓

2.

Frozen Volume

↓

3.

Notion

↓

4.

Source Code

↓

5.

현재 작업 위치

---

## 5.6 Validation

자료가 충분하지 않으면

추측하여 작성하지 않는다.

필요한 자료를 사용자에게 요청한다.

---

## 5.7 Principle

모든 자료가 확인된 이후에만

문서 작성을 시작한다.
